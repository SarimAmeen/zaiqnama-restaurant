Zaiqnama Restaurant – Online Ordering System

A Pakistani restaurant website with a 250-item menu, cart, simulated checkout (cash 15% tax / card 8% tax, PKR),
order tracking, wishlist for sold-out dishes, table reservation and a password-protected admin/kitchen dashboard.
Built with plain HTML, CSS and JavaScript (no frameworks). The whole site is one file: index.html.
Pages

Home · About Us · Menu (search, categories, cart, checkout) · Wishlist · Track Order · Contact Us (message + table reservation) · Staff/Admin
	•	GitHub Pages hosts only static files – there is no server or database. Orders, wishlist and stock are saved in each visitor's own browser (Local Storage).
So an order placed on a customer's phone is not visible on the admin's laptop. For a real shared system you need a backend such as Firebase or Supabase.
